Read and Modify POSIX File Permissions in Java

The java.nio.file.attribute package provides robust tools to read and modify standard POSIX (Portable Operating System Interface) file permissions on Unix-like operating systems like Linux and macOS. By leveraging classes such as PosixFileAttributeView, PosixFileAttributes, and the PosixFilePermissions utility, Java applications can inspect access rights, update user and group permissions, and assign security flags directly upon file creation. This guide demonstrates how to interact with POSIX permissions using modern Java NIO methods, handle string-based permission masks, and avoid common platform compatibility issues.

Core POSIX Classes in Java NIO

The NIO.2 file system API encapsulates POSIX permissions in several core types within the java.nio.file.attribute package:

  • PosixFilePermission: An enum representing individual permissions: OWNER_READ, OWNER_WRITE, OWNER_EXECUTE, GROUP_READ, GROUP_WRITE, GROUP_EXECUTE, OTHERS_READ, OTHERS_WRITE, and OTHERS_EXECUTE.
  • PosixFileAttributes: A read-only interface providing access to file metadata, including the owner, group, and the Set<PosixFilePermission>.
  • PosixFileAttributeView: An interface providing methods to read and write POSIX attributes, including updating permissions, owner, and group.
  • PosixFilePermissions: A helper class containing static methods to convert permissions between Java sets and traditional Unix rwxrwxrwx string notations.

Checking for POSIX Support

POSIX attributes are only supported on file systems that implement them (such as ext4, APFS, or ZFS). Attempting to use these APIs on unsupported platforms (like standard Windows NTFS) will throw an UnsupportedOperationException. You can check support at runtime:

import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.nio.file.attribute.PosixFileAttributeView;

Path path = Paths.get("/var/log/app.log");
boolean isPosixSupported = Files.getFileStore(path)
    .supportsFileAttributeView(PosixFileAttributeView.class);

Reading POSIX Permissions

Java offers two primary ways to retrieve permissions: using the convenience method in Files or reading the entire attributes object.

Method 1: Using Files.getPosixFilePermissions

For simple permission checks, Files.getPosixFilePermissions(Path) directly returns a Set<PosixFilePermission>:

import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.nio.file.attribute.PosixFilePermission;
import java.nio.file.attribute.PosixFilePermissions;
import java.util.Set;

Path path = Paths.get("example.txt");
Set<PosixFilePermission> permissions = Files.getPosixFilePermissions(path);

// Print permissions in POSIX string format (e.g., "rw-r--r--")
String formatted = PosixFilePermissions.toString(permissions);
System.out.println("Permissions: " + formatted);

// Check for a specific permission
if (permissions.contains(PosixFilePermission.OWNER_EXECUTE)) {
    System.out.println("The owner can execute this file.");
}

Method 2: Using PosixFileAttributes

If you also need other file metadata (such as owner, group, or timestamps), use Files.readAttributes:

import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.nio.file.attribute.PosixFileAttributes;

Path path = Paths.get("example.txt");
PosixFileAttributes attrs = Files.readAttributes(path, PosixFileAttributes.class);

System.out.println("Owner: " + attrs.owner().getName());
System.out.println("Group: " + attrs.group().getName());
System.out.println("Permissions: " + PosixFilePermissions.toString(attrs.permissions()));

Modifying POSIX Permissions

Permissions can be modified using either string-based representations or typed sets.

Method 1: Using Files.setPosixFilePermissions

The simplest approach is passing a Set<PosixFilePermission> to Files.setPosixFilePermissions:

import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.nio.file.attribute.PosixFilePermission;
import java.nio.file.attribute.PosixFilePermissions;
import java.util.Set;

Path path = Paths.get("example.txt");

// Define permissions using standard 9-character notation
Set<PosixFilePermission> perms = PosixFilePermissions.fromString("rwxr-x---");

// Apply the permissions to the file
Files.setPosixFilePermissions(path, perms);

Method 2: Using PosixFileAttributeView

When performing multiple updates (such as changing the owner and permissions simultaneously), obtain a PosixFileAttributeView:

import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.nio.file.attribute.PosixFileAttributeView;
import java.nio.file.attribute.PosixFilePermissions;

Path path = Paths.get("example.txt");
PosixFileAttributeView view = Files.getFileAttributeView(path, PosixFileAttributeView.class);

if (view != null) {
    view.setPermissions(PosixFilePermissions.fromString("rw-rw----"));
}

Setting Permissions at File Creation

To avoid race conditions where a file is briefly accessible with default permissions before being restricted, apply permissions atomically during creation using FileAttribute:

import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.nio.file.attribute.FileAttribute;
import java.nio.file.attribute.PosixFilePermission;
import java.nio.file.attribute.PosixFilePermissions;
import java.util.Set;

Set<PosixFilePermission> perms = PosixFilePermissions.fromString("rw-------");
FileAttribute<Set<PosixFilePermission>> attr = PosixFilePermissions.asFileAttribute(perms);

Path secureFile = Paths.get("credentials.key");
Files.createFile(secureFile, attr);
