Java Heap Memory Metrics Captured by jstat

The jstat (Java Virtual Machine Statistics Monitoring Tool) command-line utility provides real-time visibility into the performance and resource consumption of running HotSpot Java Virtual Machines. When monitoring Java heap memory utilization, jstat exposes critical metrics detailing the capacity, usage, and garbage collection behavior across all memory generations, including Eden, Survivor, Old, and Metaspace areas. This guide outlines the specific metrics captured by jstat—primarily through the -gc and -gccapacity sampling options—to help diagnose memory constraints, analyze GC overhead, and detect potential memory leaks.

Young Generation Metrics

The Young Generation is divided into the Eden space and two Survivor spaces (S0 and S1). jstat captures capacity and actual utilization metrics for these segments in kilobytes (KB):

  • S0C: Current Survivor space 0 capacity (KB).
  • S0U: Survivor space 0 utilization (KB).
  • S1C: Current Survivor space 1 capacity (KB).
  • S1U: Survivor space 1 utilization (KB).
  • EC: Current Eden space capacity (KB).
  • EU: Eden space utilization (KB).

When monitoring using -gccapacity, jstat also captures generation-level boundary limits:

  • NGCMN: Minimum New (Young) generation capacity (KB).
  • NGCMX: Maximum New (Young) generation capacity (KB).
  • NGC: Current New (Young) generation capacity (KB).

Old Generation Metrics

The Old (Tenured) generation stores long-lived objects promoted from the Young Generation. Key metrics include:

  • OC: Current Old space capacity (KB).
  • OU: Old space utilization (KB).
  • OGCMN: Minimum Old generation capacity (KB).
  • OGCMX: Maximum Old generation capacity (KB).
  • OGC: Current Old generation capacity (KB).

Tracking the rate of increase in OU alongside garbage collection activity is a primary method for detecting Java application memory leaks.

Metaspace and Compressed Class Space Metrics

Starting with Java 8, class metadata is stored in native memory via Metaspace (replacing the legacy Permanent Generation):

  • MC: Metaspace committed capacity (KB).
  • MU: Metaspace utilization (KB).
  • MCMN: Minimum Metaspace capacity (KB).
  • MCMX: Maximum Metaspace capacity (KB).
  • CCSC: Compressed class committed space capacity (KB).
  • CCSU: Compressed class space utilization (KB).

Garbage Collection Event and Time Metrics

In addition to instantaneous memory sizes, jstat measures garbage collection frequency and execution overhead to assess application pause times:

  • YGC: Number of Young generation garbage collection events.
  • YGCT: Cumulative time spent during Young generation garbage collections (in seconds).
  • FGC: Number of Full GC events across the entire heap.
  • FGCT: Cumulative time spent during Full GC events (in seconds).
  • GCT: Total garbage collection time (sum of YGCT and FGCT, in seconds).

Percentage Utilization Metrics (-gcutil)

When running the -gcutil flag, jstat simplifies heap monitoring by displaying utilization metrics as percentages of total available capacity rather than raw kilobyte values:

  • S0 / S1: Survivor space 0 and 1 utilization percentage.
  • E: Eden space utilization percentage.
  • O: Old generation utilization percentage.
  • M: Metaspace utilization percentage.
  • CCS: Compressed class space utilization percentage.
