Java UTF-16 High and Low Surrogates Explained

In Java, strings are encoded internally using UTF-16, which represents characters using 16-bit code units (char). While this is sufficient for common characters, it cannot represent the entire Unicode space with a single char. To accommodate supplementary characters—such as emojis and rare historical scripts—UTF-16 utilizes pairs of special 16-bit values known as surrogate pairs. This article explains the definitions of high and low surrogate characters, their technical ranges, and how Java handles them.

Unicode Code Points and the Basic Multilingual Plane

Unicode assigns every distinct character a numerical value called a code point, spanning from U+0000 to U+10FFFF. This range is split into 17 planes:

  • Basic Multilingual Plane (BMP): Covers U+0000 to U+FFFF. These characters fit inside a single 16-bit Java char.
  • Supplementary Planes: Cover U+10000 to U+10FFFF. These characters exceed 16 bits and require special handling in UTF-16.

What Are High and Low Surrogates?

Because a Java char is fixed at 16 bits, it cannot store values greater than 0xFFFF. UTF-16 resolves this by reserving a specific block of 2,048 code points in the BMP solely for encoding supplementary characters. This block is divided into two halves:

  1. High Surrogates (Leading Surrogates):
    • Range: \uD800 through \uDBFF (1,024 values).
    • Appears first in a surrogate pair.
  2. Low Surrogates (Trailing Surrogates):
    • Range: \uDC00 through \uDFFF (1,024 values).
    • Appears second in a surrogate pair.

Neither a high surrogate nor a low surrogate represents a standalone character. When combined, a high surrogate and a low surrogate form a surrogate pair, which mathematically maps to a single supplementary Unicode code point:

\[\text{Code Point} = 0x10000 + ((\text{High} - 0xD800) \times 0x400) + (\text{Low} - 0xDC00)\]

Behavior in Java

In Java, methods like String.length() count UTF-16 code units (char primitives), not actual Unicode characters (code points). Consequently, any supplementary character occupies two char locations.

For example, the musical symbol G-clef (𝄞, U+1D11E) is represented by the surrogate pair \uD834\uDD1E:

String clef = "\uD834\uDD1E";

System.out.println(clef.length()); // Outputs: 2
System.out.println(clef.codePointCount(0, clef.length())); // Outputs: 1

Essential Java Methods for Surrogates

The java.lang.Character class provides utility methods to detect and work with surrogate pairs:

  • Character.isHighSurrogate(char ch): Returns true if ch is between \uD800 and \uDBFF.
  • Character.isLowSurrogate(char ch): Returns true if ch is between \uDC00 and \uDFFF.
  • Character.isSurrogatePair(char high, char low): Verifies if the two char values form a valid sequence.
  • Character.toCodePoint(char high, char low): Converts a valid surrogate pair into its 32-bit Unicode code point integer.

To safely process characters without splitting surrogate pairs, use code-point-aware APIs such as String.codePoints() or Character.codePointAt(CharSequence seq, int index) instead of iterating through strings by raw char index.
