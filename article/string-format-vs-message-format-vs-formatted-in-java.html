String.format vs MessageFormat vs formatted in Java

Java provides multiple ways to format strings, with String.format(), String.formatted(), and java.text.MessageFormat being the most widely used. While String.format() and String.formatted() rely on standard printf-style syntax for general formatting, MessageFormat uses indexed placeholder syntax designed specifically for internationalization and localization. Choosing the right method depends on readability requirements, Java version, and whether your application requires multi-language support.

String.format()

Introduced in Java 5, String.format() is a static utility method that formats text using printf-style format specifiers such as %s, %d, and %f.

  • Syntax: String.format(String format, Object... args)
  • Placeholder style: %[argument_index$][flags][width][.precision]conversion
  • Locale support: Accepts an optional Locale parameter as the first argument. If omitted, it defaults to the system locale.
String name = "Alice";
int score = 95;
String result = String.format("User %s scored %d points.", name, score);

String.formatted()

Introduced in Java 15, formatted() is an instance method on the String class. It serves as a modern, fluent alternative to String.format().

  • Syntax: formatString.formatted(Object... args)
  • Placeholder style: Identical to String.format() (%s, %d, etc.).
  • Relationship to String.format(): Under the hood, "template %s".formatted(arg) directly delegates to String.format("template %s", arg).
  • Readability: Eliminates nested method calls, making it especially readable when combined with Java text blocks.
String result = """
    User: %s
    Score: %d
    """.formatted("Alice", 95);

java.text.MessageFormat

Part of the java.text package since Java 1.1, MessageFormat is tailored for internationalization (i18n) and localization (l10n). It allows translators to rearrange placeholders without modifying application code.

  • Syntax: MessageFormat.format(String pattern, Object... args) or via pre-compiled MessageFormat instances.
  • Placeholder style: Indexed curly braces, such as {0}, {1, number}, or {2, date, short}.
  • Special capabilities: Supports nested choice formats for handling plurals (e.g., "0 files", "1 file", "2 files").
String template = "At {1, time} on {1, date}, user {0} logged in.";
String result = MessageFormat.format(template, "Alice", new Date());

Key Differences

Feature String.format() String.formatted() MessageFormat
Java Version Java 5+ Java 15+ Java 1.1+
Invocation Static method Instance method Static or instance
Syntax Style printf (%s, %d) printf (%s, %d) Indexed braces ({0})
Primary Use Case General string building Fluent formatting, text blocks Localization and resource bundles
Argument Reordering Via %1$s indices Via %1$s indices Native via {0}, {1}
Type Formatting Basic type flags Basic type flags Built-in date, time, number, and choice formats

When to Use Which

  • Use formatted() if you are using Java 15 or later and writing standard application code, especially alongside multiline text blocks.
  • Use String.format() if you are targeting Java 14 or earlier, or when you explicitly need to pass a specific Locale object directly into the call.
  • Use MessageFormat whenever text must be extracted into resource bundles for internationalization, or when you need built-in handling for dates, times, and grammatical pluralization.
